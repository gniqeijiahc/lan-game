# 扫码联机测试（Trystero）

纯静态网页，不需要自己的服务器。

- 打开页面 → 自动生成房间和二维码
- 另一台设备扫码打开 → 自动加入 → 浏览器之间 WebRTC 直连
- 现在是聊天 + 延迟测试，确认能连通后，再把里面换成真正的小游戏

## 换信令通道

默认用 Nostr。如果连不上，在网址后面加参数再试：

- `https://用户名.github.io/仓库名/?s=torrent`
- `https://用户名.github.io/仓库名/?s=mqtt`

## 注意

- `index.html` 里的 `appId` 请改成你自己游戏的唯一名字，避免和别人撞房间。
- 手机流量（CGNAT）或严格路由器下可能打洞失败，这是 WebRTC 的限制。
